# Surface brief: landing page (site/index.html)

Scope: the public landing page on GitHub Pages (incrhst.github.io/lampstand). Mode: Persuade.
Audience: church volunteers and staff choosing a projection tool; open-source contributors.
Action: star or follow the repo on GitHub. Honest pre-release status: no download yet.
Proof: the 45 s promo video; a working demo of the operator advancing a service order; real requirement IDs from the PRD.
Constraints: static HTML and CSS plus a little vanilla JS, no build step, self-hosted fonts, WCAG 2.2 AA, video has no narration, so it gets a text summary.

## Direction contract

THESIS: the page is the church bulletin handed out at the door, the one document every congregation shares, laid open on the table. It refuses the category's dark hero, app screenshot and three feature cards.

OWN-WORLD: one sheet of goldenrod copy paper with photocopier-black ink and one violet rubber-stamp ink. Typed like the church office's typewriter (Courier Prime) under a hymnal serif (Old Standard TT). Dotted leaders, perforated tear-off card, a centre fold, rubber stamps.
