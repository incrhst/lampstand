Getting started

Build Lampstand from source and run it with a fresh library.

What you need

  • Node 22 (tested with 22.22, npm 10.9).
  • Rust 1.95 or newer (tested with 1.99).
  • The Tauri CLI comes with the npm dependencies (2.12). A global cargo tauri (tested with 2.9.4) also works.
  • On Linux, install the system libraries first: libwebkit2gtk-4.1-dev libsoup-3.0-dev libgtk-3-dev librsvg2-dev.

Run the app

git clone https://github.com/incrhst/lampstand
cd lampstand/app
npm ci
npm run tauri dev

Where your data lives

Lampstand keeps its library in the OS app-data folder (on macOS, ~/Library/Application Support/org.lampstand.app). To start from a fresh folder, set LAMPSTAND_DATA_DIR:

LAMPSTAND_DATA_DIR=/tmp/lampstand-fresh npm run tauri dev

First run

  1. Two public-domain hymns (Amazing Grace, Holy, Holy, Holy) are already in the library.
  2. Under Plan, create a service, add a song and click Open for live.
  3. Under Setup › Screens, add a window and turn it on.
  4. Under Present, press Space to advance.

To fill the library, see Songs and imports.

Build and test

The app crate embeds the built web UI, so build that once before any workspace-wide cargo command:

cd app && npm ci && npm run build && cd ..
cargo test --workspace

In app/, npm run check type-checks the UI and npm test runs its unit tests. CI runs both, plus the Rust checks, on Linux, macOS and Windows.

Contributing

Work is tracked as numbered tickets in docs/TICKETS.md. Pick one, and read How it works first to find the crate it touches. Lampstand is GPL-3.0-or-later.
